# Send Likes Bot System

نظام متكامل لإدارة وإرسال إعجابات Free Fire مع لوحة تحكم متقدمة.

## المميزات

- واجهة مستخدم جميلة لإرسال الإعجابات
- لوحة تحكم للمشرف
- نظام توليد أكواد تفعيل
- إحصائيات وتقارير مفصلة
- نظام مصادقة آمن
- قاعدة بيانات SQLite
